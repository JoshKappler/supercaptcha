Can I approve an AI agent from my phone?

Yes. Setup shows a QR code. Scan it once with your phone camera and questions start arriving on your lock screen, on iOS or Android, in the app or the browser. From the notification you approve, deny, choose an option or type a reply, and the agent keeps going.

How much does it cost?

The Agent plan is $9.99 a month after a 3-day free trial, with 5,000 notifications a month, about 160 a day. It covers every agent you run. Agent Pro, at $19.99 a month, adds unlimited notifications, budgets, and up to 5 people. See pricing

Is my code sent to Pushary’s servers?

Not on routine product paths. The decision path sends notification metadata (title, body text, tool name). Transcripts that Pushary launches are redacted and encrypted on your machine. Your phone can decrypt them, and authorized Pushary compliance admins can recover them for documented legal obligations.

How long does it take to set up?

Under 2 minutes. Run npx pushary@latest setup. It finds Claude Code, Codex, Cursor, Hermes and the other agents on your computer and connects each one, installing the Hermes plugin for you. On a Mac, the Pushary app does the same without a terminal.

How is this different from YOLO mode or auto-approve?

YOLO mode approves everything, including destructive commands. Pushary lets you set rules per tool: auto-approve safe commands (read, lint, test) and send only the dangerous ones (rm, git push, deploy) to your phone. You stay in control without the fatigue.

What AI agents work with Pushary?

Claude Code, Codex, Hermes Agent, Cursor, Windsurf, and any MCP-compatible agent. Claude Code gets permission hooks and a setup wizard. Hermes gets a native plugin with automatic error notifications.

How do I get notified when Claude Code needs permission?

Install Pushary’s hook with one command (npx pushary@latest setup). When Claude Code hits a permission prompt, you get a push notification to approve or deny from your phone. Safe tools can auto-approve, so only the decisions that matter reach you.

What are permission hooks?

Permission hooks intercept Claude Code’s tool approval prompts and route them through push notifications. When the agent wants to run a command or edit a file, you get a push to approve or deny from your phone. If you do not answer, your rule answers for you: deny, or hand back to the terminal.

What is human-in-the-loop for AI agents?

An AI agent pauses at important or risky steps and waits for a person to decide before it continues. Pushary delivers that decision to your phone as a push notification, so an autonomous agent keeps moving without you watching it, and you still catch the actions that matter.

What question types does Pushary support?

Three: confirm (yes or no), select (multiple choice with 2 to 6 options), and input (free text). Your agent picks the right type for the situation.
